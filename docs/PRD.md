# PRD — 한붓그리기 대결 (One-Stroke Duel)

> 버전 0.1 · 2026-11-22 · 상태: 초안

## 1. 개요

격자 위의 모든 칸을 **한 번에, 겹치지 않고** 지나가는 한붓그리기 퍼즐을 두 사람이 주고받는 대결 게임.
한 명(**출제자**)이 문제를 만들고, 다른 한 명(**도전자**)이 그 문제를 푼다. 역할을 번갈아 가며 더 잘 낸 / 더 빨리 푼 사람이 이긴다.

### 1.1 기본 퍼즐 규칙 (레퍼런스 화면 기준)
- 판은 N×M 격자. 일부 칸은 **빈칸(구멍)** 이라 지나갈 수 없다.
- 시작 칸에서 손가락을 떼지 않고 상·하·좌·우로 인접한 칸으로 선을 이어간다.
- 이미 지난 칸은 다시 지날 수 없다.
- 모든 활성 칸(회색)을 다 채우면(색이 바뀌면) 성공.

### 1.2 목표
| 목표 | 지표 |
|---|---|
| 친구와 바로 붙을 수 있는 가벼운 대결 경험 | 첫 대결 시작까지 30초 이내 |
| 출제 자체가 재미있는 게임 | 출제 완료율 80% 이상 |
| 반드시 풀 수 있는 문제만 출제됨 | 풀 수 없는 문제 0% (구조적으로 보장) |

### 1.3 비목표 (이번 버전에서 하지 않음)
- 회원가입 / 랭킹 / 매칭 서버
- 실시간 동시 대전(같은 문제 동시 풀기)
- 대각선 이동, 여러 번 지나야 하는 칸 같은 변형 규칙

## 2. 대상 사용자
- 친구·연인·가족끼리 휴대폰 하나로, 또는 메신저로 링크를 주고받으며 노는 캐주얼 사용자
- 모바일 세로 화면이 주 사용 환경, 데스크톱 브라우저도 지원

## 3. 핵심 아이디어: "그려서 출제한다"

출제자는 칸을 하나하나 찍는 대신 **직접 한붓그리기 경로를 그려서** 문제를 만든다.
- 출제자가 그린 경로가 지나간 칸 = 문제의 활성 칸
- 지나가지 않은 칸 = 구멍
- 따라서 출제된 문제는 **최소 한 개의 정답(출제자의 경로)이 반드시 존재** → 풀 수 없는 문제가 원천 차단됨

## 4. 게임 흐름

```
[홈] → [모드 선택] → [판 크기 선택] → [출제] → [넘기기/공유] → [풀이] → [라운드 결과] → (역할 교대) → ... → [최종 결과]
```

### 4.1 모드
| 모드 | 설명 | 우선순위 |
|---|---|---|
| **한 기기 대결 (Pass & Play)** | 한 휴대폰으로 출제 → 화면 가림 → 상대에게 넘겨서 풀이 | P0 (MVP) |
| **링크 대결** | 출제 후 문제를 URL로 공유. 상대가 링크를 열어 풀고, 결과를 다시 링크/텍스트로 회신 | P1 |
| **혼자 연습** | 자동 생성 문제를 단계별로 풀기 (레퍼런스의 Level 모드) | P2 |

서버 없이 동작하도록 문제 데이터는 URL 해시에 인코딩한다 (예: `#p=5x5.<구멍비트>.<시작칸>`).

### 4.2 출제 화면
1. 판 크기 선택: 4×4 / 5×5 / 6×6 / 7×7 (기본 5×5)
2. 빈 격자에서 아무 칸이나 눌러 시작 → 드래그로 경로를 그림
3. 되돌리기(한 칸 / 전체), 다시 그리기 지원
4. 최소 칸 수 제한: 전체 칸의 50% 이상 (너무 쉬운 문제 방지)
5. **시작점 공개 여부** 선택
   - 공개: 도전자는 정해진 칸에서 시작해야 함 (쉬움)
   - 비공개: 도전자는 아무 칸에서나 시작 가능 (기본값, 정답이 여러 개일 수 있음)
6. "출제 완료" → 출제자의 경로는 숨겨지고 활성 칸 모양만 남음

### 4.3 넘기기 화면 (Pass & Play)
- "○○님에게 휴대폰을 넘겨주세요" 가림막 화면 → "준비됐어요" 버튼으로 풀이 시작 (출제 경로 엿보기 방지)

### 4.4 풀이 화면
- 상단: 라운드, 도전자 이름, 경과 시간 타이머, 남은 칸 수
- 판: 활성 칸 = 회색, 지난 칸 = 강조색, 경로 = 흰 선, 현재 위치 = 흰 점 (레퍼런스 UI 준용)
- 조작
  - 드래그로 경로 연장, 직전 칸으로 되돌아가면 한 칸 취소
  - 손가락을 떼도 경로 유지, 끝 칸에서 다시 이어 그리기 가능
  - "처음부터" 버튼 (리셋 횟수 기록)
- 제한 시간: 기본 60초 (설정 30 / 60 / 120 / 무제한)
- 종료 조건: 모든 칸 채움(성공) / 시간 초과(실패) / 포기

### 4.5 라운드 결과 화면
- 성공 여부, 걸린 시간, 리셋 횟수
- 출제자 정답 경로 애니메이션 재생 (도전자 풀이와 다르면 "다른 정답 발견!" 표시)
- "역할 바꾸기" → 다음 라운드

## 5. 점수 / 승패 규칙

한 매치 = 기본 3라운드 × 2역할 (각자 3번 출제, 3번 풀이). 1 / 3 / 5 라운드 선택 가능.

| 상황 | 도전자 점수 | 출제자 점수 |
|---|---|---|
| 성공 | 100 + 남은 시간(초) × 2 − 리셋 × 5 (최소 50) | 0 |
| 실패 / 포기 | 0 | 100 |

- 매치 종료 시 총점이 높은 쪽 승리, 동점이면 총 풀이 시간이 짧은 쪽 승리
- 출제자는 "어렵지만 풀 수 있는" 문제를 낼수록 유리 → 출제 자체가 전략이 됨

## 6. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| F1 | 격자 렌더링 (4×4 ~ 7×7), 화면 크기에 맞춰 자동 크기 조절 | P0 |
| F2 | 터치 / 마우스 드래그로 경로 그리기, 인접 칸만 연결, 대각선·건너뛰기 무시 | P0 |
| F3 | 직전 칸으로 되돌아가면 되돌리기 | P0 |
| F4 | 출제 모드: 그린 경로로 문제 생성, 최소 칸 수 검증 | P0 |
| F5 | 풀이 모드: 완료 판정, 타이머, 리셋 | P0 |
| F6 | Pass & Play 가림막, 플레이어 이름 2명 입력 | P0 |
| F7 | 라운드 / 매치 점수 계산 및 결과 화면 | P0 |
| F8 | 출제자 정답 경로 리플레이 | P1 |
| F9 | 문제 URL 인코딩 / 디코딩, 공유 버튼 (Web Share API, 미지원 시 복사) | P1 |
| F10 | 링크 대결 결과 회신 문구 생성 ("5×5 문제 23초 만에 풀었음!") | P1 |
| F11 | 혼자 연습용 자동 문제 생성 (랜덤 경로 생성 방식) | P2 |
| F12 | 효과음 / 진동 피드백 (성공, 실패, 칸 채움) | P2 |

## 7. 비기능 요구사항
- **플랫폼**: 모바일 웹 우선, 단일 `index.html` (외부 의존성 없음), 오프라인 동작
- **성능**: 드래그 입력 지연 16ms 이내 (60fps), 7×7에서도 끊김 없음
- **입력**: 손가락이 칸 경계에 걸쳐도 오입력이 없도록 칸 중심 기준 판정 반경 적용, 스크롤·확대 제스처 차단
- **접근성**: 색 외에 선/점으로도 상태 구분, 다크 배경 + 고대비 색상
- **저장**: 진행 중인 매치는 localStorage에 저장해 새로고침 후 이어하기 (실패해도 게임은 동작)

## 8. 화면 목록
1. 홈 (대결 시작 / 링크로 받은 문제 / 연습)
2. 매치 설정 (플레이어 이름, 판 크기, 라운드 수, 제한 시간)
3. 출제
4. 넘기기 가림막
5. 풀이
6. 라운드 결과
7. 최종 결과 (승자, 라운드별 기록, 다시하기)

## 9. 데이터 모델 (요약)

```js
Puzzle  { rows, cols, cells: boolean[],  // true = 활성 칸
          start: number | null,          // 시작점 공개 시 칸 index
          solution: number[] }           // 출제자 경로 (리플레이용)
Attempt { path: number[], timeMs, resets, result: 'solved'|'timeout'|'gaveup' }
Match   { players: [A, B], rounds, timeLimit, history: { setter, solver, puzzle, attempt, scores }[] }
```
